# Music Charts

Various charts, diagrams, and documents intended to aid myself/others in my/their musical education journey.

## Requirements

You'll need a LaTeX distribution to work with these files.
[TeX Live](https://www.tug.org/texlive/) is a good place to start.

## Recommended Tooling

I like using [Visual Studio Code](https://code.visualstudio.com) with the [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) extension.
